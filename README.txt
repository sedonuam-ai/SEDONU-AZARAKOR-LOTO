ÉTAPE 1 — Créer le dépôt GitHub
────────────────────────────────
  1. github.com → bouton vert "New"
  2. Repository name : sedonu-azarakor   ← NOM EXACT
  3. Visibilité : ● Public
  4. NE PAS cocher "Add a README file"
  5. "Create repository"

ÉTAPE 2 — Uploader les fichiers
────────────────────────────────
  1. Dans le dépôt vide → "uploading an existing file"
  2. Glissez-déposez TOUT le contenu de ce ZIP :
       ✓ index.html
       ✓ manifest.json
       ✓ sw.js
       ✓ .nojekyll         ← fichier caché, important !
       ✓ dossier icons/    (avec tous les PNG)
  3. "Commit changes"

ÉTAPE 3 — Activer GitHub Pages
────────────────────────────────
  1. Onglet "Settings"
  2. Menu gauche → "Pages"
  3. Source : Branch "main" | "/ (root)"
  4. "Save"
  5. Attendre 3 minutes
  6. Votre URL : https://VOTRE-PSEUDO.github.io/sedonu-azarakor/

ÉTAPE 4 — Installer sur Android
────────────────────────────────
  1. Ouvrez Chrome sur votre Android
  2. Tapez votre URL GitHub Pages
  3. Attendez 10 secondes sur la page
  4. Chrome affiche en bas :
     ┌──────────────────────────────────┐
     │ ◆  Installer SEDONU AZARAKOR     │
     │    [Annuler]    [Installer]      │
     └──────────────────────────────────┘
  5. Appuyez "Installer"
  6. L'icône ◆ or apparaît sur l'écran d'accueil !

SI LA BOÎTE N'APPARAÎT PAS :
  → Attendez que GitHub Pages soit actif (onglet Settings > Pages)
  → Rechargez la page 2 fois
  → Fermez Chrome complètement et rouvrez l'URL
